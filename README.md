# HomeHackery

### Because "Stock" is Boring.

Welcome to **HomeHackery** — a collection of DIY electronics, automation, and just-for-the-fun-of-it projects.

I build things because I want to know **how they work, how they can be improved, and sometimes just to see if I can make them do something they weren't designed to do.**

## 🔧 What You'll Find Here

* ESP32 and Arduino projects
* Home automation and monitoring
* Custom electronics
* Displays and countdown timers
* DIY modifications and upgrades
* 3D-printed parts and enclosures
* Experiments, hacks, and things that seemed like a good idea at the time

## 🚧 Current Project

### NBC Dual Holiday Countdown Display

A modified *The Nightmare Before Christmas* display featuring independently controlled Halloween and Christmas countdowns.

Built around an ESP32-C3 with a web-based configuration interface and OTA firmware updates.

**Currently in development — firmware and documentation are still evolving.**

[View the project →](https://github.com/planedoctor/NBC_Dual_Holiday_Countdown_Display)
